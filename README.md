# RedStore

A responsive e-commerce frontend built with HTML, CSS and vanilla JavaScript.

## Features
- Homepage with product browsing
- Login / logout and user menu
- Shopping cart
- Clean, responsive layout

## Tech Used
- HTML5
- CSS3
- JavaScript (vanilla)

## Project Structure
- `index.html` – page structure
- `style.css` – styling
- `script.js` – interactivity and cart logic

## How to Run
1. Clone the repo:
   git clone https://github.com/somaygahlot09/RedStore.git

2. Open `index.html` in your browser.
